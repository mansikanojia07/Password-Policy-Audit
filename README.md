# Password Policy Audit

**Internship Project – Task 02**

## About the Project
This project focuses on reviewing a sample password policy, identifying weak password rules, and creating an improved policy based on NIST guidelines.

## Topics Covered
- Password Security
- Weak Password Rules
- NIST Guidelines
- Improved Password Policy
- Staff Password Safety Guide

## Objective
To understand how effective password policies can improve account security while remaining user-friendly.
